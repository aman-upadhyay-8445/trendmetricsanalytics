## 🛠️ Setup Instructions

### Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. All pages are static HTML - no build process required

### Google Sheets Integration

1. Follow instructions in `SETUP_INSTRUCTIONS.md`
2. Deploy `google-apps-script.js` to Google Apps Script
3. Update the Web App URL in `contact.html`

### Lead Alerts Setup

1. Follow instructions in `LEAD_ALERTS_SETUP.md`
2. Configure email alerts in Google Apps Script
3. Optional: Set up WhatsApp alerts via Twilio

## 📧 Contact Form

The contact form automatically saves submissions to Google Sheets and sends email alerts. See `SETUP_INSTRUCTIONS.md` for configuration.
